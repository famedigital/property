# Project Focus & Phasing

**Updated:** 2026-09-20

## Groundwork sequence

1. **Local building IoT first** — field kit and gateways at buildings (already underway / available).  
2. **This project focuses NOW on three building products:**
   - **Escrow rental** (no owner roster to RRCO)
   - **Cleaning ops** with **biometric + CCTV (or alternate) proof** of worker attendance
   - **Water IoT per individual building** (tank / inlet alerts)
3. **Main source / Pamtsho WTP complete ERP** — blueprint ready, **implement later** after building product works.

```text
NOW                          LATER
─────────────────────────    ──────────────────────────
Escrow rent                   Pamtsho WTP ERP (Thromde)
Cleaning + biometric/CCTV     Main-source corridor SCADA-class
Building water IoT            Multi-plant municipal expand
Local building gateways
```
