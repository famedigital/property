## Groundwork sequence

1. **Local building IoT first** — field kit and gateways at buildings (already underway / available).  
2. **This project focuses NOW on building products:**
   - **Unit listing & leasing** — vacancies, photos (+ optional 3D), pay security → secured
   - **Escrow rental** (no owner roster to RRCO)
   - **Cleaning** with biometric + CCTV/alternate proof

   - **Full AI** for Owner/PM dashboards + prospect/resident clients (Gateway API key)
3. **Pamtsho WTP ERP** — later.
