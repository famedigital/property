# Velora — Brand

**Name:** Velora  
**Pronunciation:** *veh-LOR-ah*  
**Tagline:** Property, settled.  
**Theme:** [Darkmatter](https://tweakcn.com/r/themes/darkmatter.json) (already chosen)

---

## Why this name

Soft **-ora** ending (same family as Finora / Linora), but quieter and less “fintech.”  
**Vel-** suggests veil / calm cover — not hustle, not neon PropTech.  
It reads as settled ownership: rent collected, buildings cared for, water watched — without noise.

| Considered | Why not chosen |
|---|---|
| Finora | Strong, but leans finance-only |
| Linora | Soft and good — kept as alternate |
| Restora | Clear “care” story, slightly heavier |
| Ashlar | Beautiful stone word; harder to say / spell |
| Stedra | Settled, but colder |

**Alternate if you prefer:** Linora (same system, swap the wordmark).

---

## One-line product

**Velora** is quiet building ops: listings → security escrow → secured lease, escrow rent, cleaning proof, building water — with Ask AI when you need it.

## Voice

| Do | Don’t |
|---|---|
| Calm, precise, short | Hype, “disrupt”, emoji clutter |
| “Escrow settled to owner” | “Revolutionize rent collection!!!” |

## Visual identity (with Darkmatter)

| Element | Spec |
|---|---|
| **Wordmark** | `Velora` in **Geist Mono**, medium/semibold, tracking normal |
| **Accent** | Amber primary — one mark on the **V** stem or a 2px underline on hover/active |
| **Mark (optional)** | Soft door/portal: two verticals + soft lintel — never a house icon, never a water drop |
| **Surfaces** | Charcoal background, muted panels, teal only for water |
| **Radius** | `0.75rem` |
| **Default mode** | Dark |

### Wordmark treatments

```text
Velora              ← primary (sidebar, login, PDF)
VELORA              ← rare; invoices / legal header only
Ask Velora          ← AI affordance (not “AI Assistant”)
```

### Don’t

- Gradient logos, purple glow, 3D house glyphs  
- Pill-stacked marketing badges in the first viewport  
- Inter / Roboto / system as brand UI font
