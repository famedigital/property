1. How the UI will look

Default = dark. Same CSS variables drive light mode later. Not soft SaaS — technical PMS.

Background charcoal oklch ~0.18
Foreground soft gray-white
Primary amber — CTAs, Ask AI
Secondary muted teal — water
Muted panels / rows
Destructive teal danger

Layout language

  • Owner/PM web: left sidebar + top bar (“Ask AI”) + dense tables
  • Prospect: full-bleed listing gallery, minimal chrome
  • Resident / Worker: bottom tabs, large amber primary CTAs
  • Cards only for listing gallery + proof packs — ops stays tables
  • Status chips: vacant listed secured overdue P0
  • Fonts: Geist Mono UI · JetBrains Mono IDs/code
  • Radius 0.75rem — soft, not pill-heavy
