Pay security → get secured

  1. Prospect applies → PM/Owner approves → unit reserved
  2. Prospect pays security deposit (+ optional first rent) into escrow
  3. Webhook confirms → lease created → unit secured → listing closes
  4. Handover checklist + keys/access → monthly escrow rent begins
Secured = deposit cleared in escrow + lease active — not “manager said they paid.”

4. Escrow rent + RRCO boundary

Residents pay into platform escrow. Owners get scheduled settlement. Manager never holds rent.

RRCO: No export of owner roster / rent rolls. Owners self-file PIT with settlement PDFs. Platform keeps KYC internal.
flowchart LR Res["Resident / prospect"] -->|rent or security| Escrow["Platform escrow bank"] Escrow -->|settlement| Owner["Owner bank"] Escrow -->|PM fee| PM["Manager"] Escrow -->|SaaS fee| Plat["Platform"] Escrow -.->|NO roster| RRCO["RRCO"] Owner -->|self files PIT| RRCO
  • Tables: escrow_accounts, escrow_ledger_entries, owner_payouts, security deposit entries
  • Immutable ledger; no silent mark-paid; owner sees expected vs collected
