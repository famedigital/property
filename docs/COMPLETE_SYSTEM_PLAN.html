3. Escrow rent + RRCO boundary

Residents pay into platform escrow. Owners get scheduled settlement. Manager never holds rent.

RRCO: Do not export owner roster / rent rolls. Owners self-file PIT using settlement PDFs.

  • Tables: escrow_accounts, escrow_ledger_entries, owner_payouts
  • No silent mark-paid; immutable ledger; owner sees expected vs collected
